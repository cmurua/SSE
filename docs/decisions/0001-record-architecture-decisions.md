# ADR 0001 — Registrar decisiones de arquitectura

## Estado
Aceptado.

## Contexto
El proyecto necesita dejar registro de decisiones tecnicas para que
futuras personas (o el propio equipo, mas adelante) entiendan el porque,
no solo el que.

## Decision
Usar ADRs cortos en `docs/decisions/`, numerados secuencialmente. Cada
uno documenta contexto, decision y consecuencias.
